# 商城行为分析模块设计文档

## 1. 项目概述

### 1.1 模块目标
基于现有的商城小程序系统，构建一个完整的用户行为分析模块，通过收集、分析和展示用户在小程序中的行为数据，为运营决策和产品优化提供数据支撑。

### 1.2 核心功能
- **数据采集**: 前端自动埋点收集用户行为数据
- **数据存储**: 高效存储和管理行为数据
- **数据分析**: 多维度行为分析和统计
- **数据展示**: 直观的图表和报表展示
- **实时监控**: 实时数据监控和预警

## 2. 系统架构设计

### 2.1 整体架构
```
前端小程序 → 行为数据采集 → API接口 → 数据处理服务 → 数据存储 → 分析服务 → 可视化展示
```

### 2.2 技术选型
- **后端框架**: Flask (与现有系统保持一致)
- **数据库**: MySQL (主数据) + Redis (缓存)
- **消息队列**: Celery + Redis (异步处理)
- **数据可视化**: ECharts (图表展示)
- **实时处理**: WebSocket (实时数据推送)

## 7. 前端集成方案

### 7.1 自动埋点方案
```javascript
// behavior-tracker.js
class BehaviorTracker {
  constructor() {
    this.sessionId = this.generateSessionId();
    this.userId = this.getUserId();
    this.initTracking();
  }
  
  // 初始化追踪
  initTracking() {
    this.trackPageView();
    this.trackUserInteractions();
    this.trackProductEvents();
    this.trackOrderEvents();
  }
  
  // 页面访问追踪
  trackPageView() {
    const pageInfo = this.getPageInfo();
    this.trackEvent('page_view', '页面访问', {
      page_path: pageInfo.path,
      stay_duration: 0,
      referrer: pageInfo.referrer
    });
  }
  
  // 用户交互追踪
  trackUserInteractions() {
    // 点击事件
    document.addEventListener('click', (e) => {
      this.trackEvent('click', '点击事件', {
        element_id: e.target.id || e.target.className,
        click_position: {x: e.clientX, y: e.clientY}
      });
    });
    
    // 滚动事件
    let scrollTimer;
    document.addEventListener('scroll', () => {
      clearTimeout(scrollTimer);
      scrollTimer = setTimeout(() => {
        this.trackEvent('scroll', '滚动事件', {
          scroll_depth: this.getScrollDepth()
        });
      }, 1000);
    });
  }
  
  // 商品事件追踪
  trackProductEvents() {
    // 商品浏览
    this.trackEvent('product_view', '商品浏览', {
      product_id: this.getProductId()
    });
    
    // 加入购物车
    this.trackAddToCart();
    
    // 收藏商品
    this.trackFavorite();
  }
  
  // 订单事件追踪
  trackOrderEvents() {
    // 创建订单
    this.trackEvent('order_create', '创建订单', {
      order_id: this.getOrderId(),
      order_amount: this.getOrderAmount()
    });
    
    // 订单支付
    this.trackEvent('order_pay', '订单支付', {
      order_id: this.getOrderId(),
      payment_method: this.getPaymentMethod()
    });
  }
  
  // 上报事件数据
  trackEvent(eventType, eventName, properties = {}) {
    const eventData = {
      event_type: eventType,
      event_name: eventName,
      session_id: this.sessionId,
      user_id: this.userId,
      properties: properties,
      device_info: this.getDeviceInfo(),
      timestamp: Date.now()
    };
    
    // 发送到后端
    this.sendToServer(eventData);
  }
  
  // 发送数据到服务器
  sendToServer(eventData) {
    wx.request({
      url: '/api/v1/behavior/track',
      method: 'POST',
      data: eventData,
      success: (res) => {
        console.log('行为数据上报成功:', res);
      },
      fail: (err) => {
        console.error('行为数据上报失败:', err);
      }
    });
  }
}
```
